# 开关清单 —— 什么会被记、什么不会、哪里能调

> 这份是给「想改行为又不想翻代码」看的。每条都标了**在哪个文件**、**改了会怎样**。
> 最后更新 2026-11-07（0.4.4）

---

## 一、什么会被记下来

自动沉淀挂在每轮结束（`agent/turn-stopping`）。抓这一轮新增的 user / assistant 消息，
**剥掉噪音之后**剩下的才进判定。

### 1.1 先剥掉这些东西（整条扔掉，不记）

| 剥什么 | 例子 | 在哪 |
|---|---|---|
| 压缩检查点 | `<compacted-summary>` 开头、`This is an automatically generated checkpoint` 开头 | `capture.mjs` `COMPACTION_MARKER` |
| 系统/环境注入 | `Current working directory:`、`Runtime context`、`DSH file policy`、`Approval prompts are disabled` | `capture.mjs` `SYSTEM_INJECTION_MARKER` |
| 系统通知 | `The approval policy changed from ...` | 同上 |
| 定时任务提示词 | `（到谷时啦，去 B 站刷一轮吧...` | 同上 |

> **为什么这条最要紧**：库里原来躺着 8 份 `The approval policy changed`、4 份定时任务 prompt。
> 这些不是谁说的话，记进去只会污染检索。

### 1.2 再剥掉行内标记（留着正文）

| 剥什么 | 例子 |
|---|---|
| 表情/提醒尾巴 | `[提醒:只写正文收不到]`、`[可选表情:...]`、`[表情:...]`、`[系统提示:...]` |
| QQ 来源头 | `[QQ会话 group:903875146｜本条消息ID 61159603]` → 提进 `chat_key` 字段 |
| 其它标记 | `[关键词:...]`、`[群聊上文]`、`[接上条]`、`[本群记忆:...]` |
| 失效路径 | `[图: C:\...\Temp\...gif]`（临时文件早没了） |
| 空标记 | `[表情]`、`[图片]` |

**保留的**：`[咕咕的嘎(QQ:727781694)]:` 这种署名 —— 那是"谁说的"，有信息。

剥完变空的整条丢掉。

### 1.3 门槛

| 门槛 | 值 | 在哪 | 含义 |
|---|---:|---|---|
| 最小轮次长度 | **60 字** | `capture.mjs` `MIN_TURN_CHARS` | 一轮话太少就不问模型，直接进闲聊池、40 分 |
| 废料池长度 | **400 字** | `capture.mjs` | 超过 400 字 + 模型判"没信息量" → 进 trash（留档，但不挂事、不参加匹配） |

## 二、谁说了算（三层判断）

| 判断 | 谁做 | 说明 |
|---|---|---|
| 这条归哪件事 / 多少分 / 什么情绪 / 是不是决定 / 哪个门类 | **模型** | 每轮多一次 LLM 调用 |
| 这条**取代了哪几条旧记忆**（A4） | **我** | `memory_write` 的 `supersedes` 参数。判据见下 |
| 投影里放哪 10 条 | **人（老爸/我）** | `memories.pinned = 1`，手工钉 |

### A4 该标什么、不该标什么（老爸 2026-11-07 定）

> 只标「影响情感」的、「对前后文有影响」的。
> 一次性调度（MAA 先停、下一跳排程）不用标 —— 它们过期了也不影响谁。

| 该标 | 不该标 |
|---|---|
| 称呼从「阿水」改成「老爸」 | 「MAA 先停两天」 |
| 压缩阈值 0.6 → 0.9 | 「下一跳排到 22:00」 |
| 「备份改到 D 盘」 | 「这轮先不跑」 |
| 「窗口改成三个月」 | 一般的任务进度 |

被标的旧话**不删**，只是检索时默认不冒头；`includeSuperseded: true` 能翻到。

## 三、取的时候怎么取

### 3.1 默认参数

| 参数 | 默认 | 在哪 | 说明 |
|---|---|---|---|
| `windowDays` | **90 天** | `memory_search` / `query.mjs` | 全库检索太慢（13.6 万条要 2 秒），90 天窗口 233~553ms。**传 0 = 不限**（0.4.5 之前这个开关是坏的，`Number(0) \|\| 90` 吃成 90） |
| 时间词 | 自动 | `query.mjs` `parseTimeHint()` | 「昨天/上次/以前/最近三天」会被认出来，改写上面两个参数（0.4.5） |
| 含沉底（sunk） | 不含 | `search2.mjs` `includeSunk` | 沉底 = 180 天没被取到，权重 ×0.4 但还能搜到 |
| 含被取代 | 不含 | `search2.mjs` `includeSuperseded` | 见上面 A4 |

### 3.2 检索打分怎么算

```
分数 = IDF 之和 × 长度归一 × (0.5 + α×0.5) × β 惩罚 × 沉底惩罚 × 时间衰减
```

> 时间衰减只在查询里带「上次 / 最近」时起作用（0.4.5），90 天半程，最重 ×2。翻旧账（「以前」）不带 —— 那时候把新的往上推是错的。

| 因子 | 干什么 |
|---|---|
| IDF | 稀有词权重高（在**候选集**上算，不扫全库） |
| 长度归一 | 长条目不能靠字数堆分数 |
| α | 重要度（0~1） |
| β | 可信度惩罚 |
| 沉底 | ×0.4 |

分词：中文 2-gram + 单字 + 英文整词。同义词表在 `lib/terms.json`（组数以文件为准）。

**想退回旧检索**：环境变量 `MINDSEA_SEARCH_V2=0`。

## 四、可调开关一览

| 开关 | 位置 | 默认 | 改了会怎样 |
|---|---|---|---|
| `dbPath` | profile 的 `cordis.patch.yml` | 插件目录上一层 `sea2.db` | 换库位置 |
| `autoCapture` | 同上 | `true` | 关掉 = 只读，不写新记忆 |
| `captureProvider` / `captureModel` | 同上 | 跟当前会话同款 | 判工用专门的小模型省钱 |
| `captureMaxTokens` | 同上 | 2000 | 判工回答长度上限 |
| `MINDSEA_SEARCH_V2` | 环境变量 | 开 | `=0` 退回旧检索 |
| `MIN_TURN_CHARS` | `capture.mjs` 常量 | 60 | 调大 = 短轮次不记 |
| `STORE_MAX_CHARS` | `capture.mjs` 常量 | 见文件 | 单条正文截断长度 |
| `BUDGET` | `lib/project.mjs` | 480 字 / 10 条 / 每行 40 字 | 投影大小 |

## 五、上库前该确认的（我补的）

### 5.1 备份方式

**别用 `Copy-Item sea2.db`** —— 库是 WAL 模式，8 MB 新数据可能在 `-wal` 里没落盘，
拷主文件只能拿到旧快照（我第一次就踩了这个）。

```
VACUUM INTO '备份路径'
```

### 5.2 删数据时注意外键

`decisions.memory_id` 指向 `memories.id`。删 memories 之前要么先删 decisions，
要么把 `memory_id` 置空（**决定本身有内容，不该跟着噪音一起没**）。

清洗时我第一版就是直接删，结果带走了 6 条决定（「温柔向刷B站口径」那批）。

### 5.3 三个列是给"以后"用的，别急着回填

`session` / `superseded_by` / `chat_key` 都是加列，旧行留空。
旧行补不回来是正常的（当时没存），**别硬造**。

### 5.4 什么情况下会再变脏

| 情况 | 会不会再发生 |
|---|---|
| 系统通知 / 定时任务 prompt 被记 | ✅ 已堵（`SYSTEM_INJECTION_MARKER`） |
| QQ 尾巴 | ✅ 已堵（`RUNTIME_TAIL`） |
| 同一句话说了很多次 | ❌ 会继续记 —— 那是真的说了很多次，不该合并 |
| 新的插件又塞新标记 | ⚠️ 得再看一遍正则 |

**判断标准**：跑一轮之后查

```sql
SELECT text, count(*) n FROM memories GROUP BY text HAVING n > 1 ORDER BY n DESC LIMIT 10;
```

如果前几名又是系统注入，就是有新的没剥干净。

### 5.5 回滚

| 层 | 怎么退 |
|---|---|
| 库 | 用 `VACUUM INTO` 的备份覆盖 |
| 代码 | `git reset --hard <commit>` |
| 插件不加载 | `plugin_manager` 把 `include:mindsea` 设 `false` |
